The loop

One model call is a guess. A loop is a system.

Python holds the loop: it calls the model, checks the work against a test, and runs it again until it passes. Then it logs what happened.

01

Call

An LLM step, an ML model, a tool, an MCP server. One job each.

02

Check

Python and a test decide whether the step passed. Not the model.

03

Repeat

Fail goes back with the reason. Pass moves on, and every pass is logged.

Python is the ground truth. The model works inside it, never above it.loop.py
