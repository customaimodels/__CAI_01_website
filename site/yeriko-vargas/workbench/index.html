From my Terminal

A clean desktop is one line away.

zsh · hide the desktop icons
defaults write com.apple.finder CreateDesktop false
killall Finder
zsh · bring them back
defaults write com.apple.finder CreateDesktop true
killall Finder

The keys I reach for

Hands stay on the keyboard.

macOS

  • ⌘ Spaceopen anything
  • ⌘ ⇧ .show hidden files
  • ⌘ ⇧ 4screenshot an area
  • ⌘ ⌥ Escforce quit
  • ⌘ `next window, same app
  • ⌃ ⌘ Qlock the screen

Terminal

  • ⌃ Rsearch my history
  • ⌃ A · ⌃ Estart · end of line
  • ⌃ Cstop it
  • ⌃ Lclean screen
  • !!run the last one again
  • cd -back where I was

Excel

  • ⌘ ↓ →jump to the edge of the data
  • ⌘ ⇧ ↓select to the end
  • ⌘ Tmake it a table
  • ⌘ ;today's date
  • ⌘ Dfill down
  • F4lock a reference
