CascForward: build it, automate it, preserve what works.

A Python-first system for turning ideas and AI-assisted workflows into structured, reusable software. AI does the parts that need reasoning; everything repeatable moves into Python that runs the same way every time.

The rule underneath

The model reasons. Python repeats.

Validation, reproducibility, cost control and failure recovery are built in, not added after.

Prototype 02 · The scaffold and the function system

File = stage. Function = action. Pipeline = story. Print = report.

One command lays out a whole project: a menu that finds every builder, a collector that feeds them, numbered stages inside each one. Every function is named so it reads like a sentence, checks what comes in, and reports what it did. This is how I keep code readable after years of changes, and how I find a failure in one look.

import os
import sys
import subprocess
 
ROOT = os.path.dirname(os.path.abspath(__file__))

def clear():
    os.system("cls" if os.name == "nt" else "clear")

    if os.path.exists(CSV_PATH):
        try:
            import pandas as pd
            df = pd.read_csv(CSV_PATH)
            return f"df available  {len(df)} rows"
        except Exception:
            return "df exists (unreadable)"
    return "no df"
 
 
def find_runners():
    runners = []
    for entry in sorted(os.listdir(ROOT)):
        if entry.startswith("builders_"):
            domain_path = os.path.join(ROOT, entry)
            for builder in sorted(os.listdir(domain_path)):
                run_py = os.path.join(domain_path, builder, "run.py")
                if os.path.exists(run_py):
                    runners.append((builder, run_py))
    return runners
 
 
def show_menu(runners):
    print("\n" + "=" * 44)
    print("   MAIN MENU")
    print("=" * 44)

    print()

    print("   [Q]  Quit")

## collector.py — full implementation
 
Copy the full collector.py from `music_code_structure/collector.py` as the canonical template.
It implements: `_new`, `_append`, `_replace`, `_view`, `_filter`, `_clear`, `menu()`, `main()`.
Menu options:
- **[N] New** — fresh collection, replaces df
- **[A] Append** — adds rows, dedupes by file_path
- **[R] Replace** — preview current df then swap with new input
- **[V] View** — shape, columns, extension breakdown with bar, total size MB, head(5)
- **[F] Filter** — filter by extension(s), optionally save filtered result
- **[X] Clear** — delete _df_collect.csv with confirmation
- **[B] Back** — return to auto.py menu
Status line always shows: row count + top extensions with counts.

# /struct — Create a new app project with standard structure
 
This is the general-purpose project structure used across all domains (music, finance, etc.).
 
## ⚠️ PORTABILITY RULE — ENFORCE ALWAYS
 
**This app must work on any machine, in any folder, without modification.**
 
- **ZERO hardcoded external paths** anywhere in the project — not in functions, not in run.py, not in config files
- All internal paths are computed at runtime using `os.path.dirname(os.path.abspath(__file__))` as the anchor
- `_df_collect.csv` lives at project root and is always located relative to `__file__`
- The **only** file that ever touches external/desktop paths is `export_2_desk.py` — that is its entire purpose
- If you ever see an absolute path like `/Users/...` or `C:\...` inside any file except `export_2_desk.py`, it is a bug
 
## ROLE OF EACH ROOT FILE
 
| File | Role |
|------|------|
| `auto.py` | Loop menu — orchestrates builders and collector |
| `collector.py` | Builds `_df_collect.csv` — the df we work on |
| `export_2_desk.py` | **Only file with external/desktop paths** — highly customizable per project; copies builder exports to desktop with appropriate naming/format |
| `_df_collect.csv` | The working dataframe — input to all builders |
 
## Collector note
`collector.py` is the one file that may vary by domain. When the user invokes `/struct` for the first time on a new project, ask: **"Does this project need a custom collector, or use the standard file/folder collector?"**
- **Standard**: file/folder walker → `_df_collect.csv` (copy as-is from template)
- **Custom**: user will describe the data source (API, database, spreadsheet, etc.) — adapt `collector.py` for that source while keeping the same menu structure (`menu()`) and CSV output contract (`_df_collect.csv`)

def _append(path, row):
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "a", encoding="utf-8") as f:
        f.write(json.dumps(row, ensure_ascii=False) + "\n")
 
 
def make_server(schema, paths=PATHS, cfg=CFG, port=None):
    class Handler(SimpleHTTPRequestHandler):
        def __init__(self, *a, **k):
            super().__init__(*a, directory=paths["dist"], **k)
 
        def log_message(self, *a):
            pass
 
        def _send(self, code, body):
            data = json.dumps(body).encode()
            self.send_response(code)
            self.send_header("Content-Type", "application/json")
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)
 
        def do_POST(self):
            n = int(self.headers.get("Content-Length") or 0)
            if n > cfg["MAX_BODY_BYTES"]:
                return self._send(413, {"ok": False, "errors": ["too big"]})
            try:
                body = json.loads(self.rfile.read(n) or b"null")
            except ValueError:
                return self._send(400, {"ok": False, "errors": ["not json"]})
            now = datetime.now(timezone.utc).isoformat(timespec="seconds")
            if self.path == "/submit":
                errors = validate_payload(schema, body, cfg)
                if errors:
                    return self._send(400, {"ok": False, "errors": errors})
                _append(os.path.join(paths["raw"], "submissions.jsonl"), {"at": now, **body})
                return self._send(200, {"ok": True})
            if self.path == "/step" and isinstance(body, dict) and str(body.get("layer", "")).isdigit():
                _append(os.path.join(paths["raw"], "steps.jsonl"),
                        {"at": now, "visit": str(body.get("visit", ""))[:16], "layer": int(body["layer"])})
                return self._send(200, {"ok": True})
            return self._send(404, {"ok": False, "errors": ["no such route"]})
 
    return ThreadingHTTPServer(("127.0.0.1", cfg["PORT"] if port is None else port), Handler)

"""_2 process — check every layer before anything is written. Markup and schema must agree. Fails fast."""
import re
import time
 
from src_web._5_util_web import hr, summary
 
 
def process(site, paths, cfg):
    t0 = time.time()
    hr("PROCESS")
    errors, seen = [], set()
    if not site["layers"]:
        errors.append("no layers found")
    for layer in site["layers"]:
        name, sch = layer["name"], layer["schema"]
        if not sch.get("title"):
            errors.append(f"{name}: schema has no title")
        if not sch.get("fields"):
            errors.append(f"{name}: schema has no fields")
        for f in sch.get("fields", []):
            fn = f.get("name", "")
            if not re.fullmatch(r"[a-z][a-z0-9_]*", fn):
                errors.append(f"{name}: bad field name {fn!r}")
            if fn in seen:
                errors.append(f"{name}: field {fn} used twice")
            seen.add(fn)
            if f.get("type") not in cfg["FIELD_TYPES"]:
                errors.append(f"{name}: {fn} has unknown type {f.get('type')!r}")
            if f.get("type") == "choice" and not f.get("options"):
                errors.append(f"{name}: choice {fn} has no options")
            if f'name="{fn}"' not in layer["html"]:
                errors.append(f"{name}: {fn} is in schema.json but not in layer.html")
        for fn in re.findall(r'name="([^"]+)"', layer["html"]):
            if fn not in {f.get("name") for f in sch.get("fields", [])}:
                errors.append(f"{name}: {fn} is in layer.html but not in schema.json")
    for e in errors:
        print(f"   ✗ {e}")
    summary("_2_proc_webschema_check_GET_site", "PROC", len(site["layers"]), len(site["layers"]), len(errors), t0)
    if errors:
        raise ValueError(f"{len(errors)} layer error(s): fix them before building")
    return site
