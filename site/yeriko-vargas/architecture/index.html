Pattern 01 · The builder

One folder. One command. The whole pipeline.

A builder is a self-contained mini-app: python run.py runs the full pipeline. It lives inside a project but runs on its own, and a shared selector at the project root feeds every builder the same way.

00select

rows in: collect, filter, scan or one path

01build

validate · normalize

02process

tag · classify

03extract

→ data/processed

04analyze

→ data/exports

$ /builder_str <name> <domain>

    │   ├── _4_ana_<domain>.py   ← analyze + save to data/exports/
    │   └── _5_util_<domain>.py  ← shared helpers; only file other stages import
    └── data/
        ├── raw/.gitkeep
        ├── processed/.gitkeep
        └── exports/.gitkeep

No config/ at scaffold time. CFG lives inline in run.py until the project grows.

The stage contract · enforced always

every stageone signature3 lines 
def fn(df, paths, cfg):   # receives df, returns df
    ...
    return df
  • Pure flowdf in, df out. Every stage receives the frame and returns it.
  • Single source of pathsBuilt once in run.py from __file__, never inside a stage.
  • Config is datacfg is defined once: numbers, flags, names. Never paths.
  • One-way dependencies_5_util is the only cross-import. Stages never import each other.

import os
import pandas as pd
 
_HERE = os.path.dirname(os.path.abspath(__file__))
_CSV  = os.path.join(_HERE, "_df_collect.csv")
 
 
def select():
    """Returns a DataFrame. Always the first call in any builder run.py."""
    print("\n  [selector]  use rows?  [Enter = full collect   s = select]  ", end="", flush=True)
    choice = input().strip().lower()
 
    if choice == "s":
        return _select_mode()
    return _default()
 
 
def _default():
    if os.path.exists(_CSV):
        df = pd.read_csv(_CSV)
        print(f"  [selector]  →  {len(df)} rows  (_df_collect.csv)")
        return df
    print("  [selector]  no _df_collect.csv found — returning empty df")
    return pd.DataFrame()
 
 
def _select_mode():
    if os.path.exists(_CSV):
        return _filter_collect()
    return _from_input()
 
 
def _filter_collect():
    df = pd.read_csv(_CSV)
    print(f"\n  collect:  {len(df)} rows   cols: {list(df.columns)}")
 
    if "extension" in df.columns:
        counts = df["extension"].value_counts()
        print("\n  extensions:")
        for ext, n in counts.items():
            print(f"    {ext:<12} {n}")
        val = input("\n  filter by extension  (comma-sep, or Enter to skip): ").strip()
        if val:
            wanted = [e.strip() for e in val.split(",")]
            df = df[df["extension"].isin(wanted)].reset_index(drop=True)
 
    print(f"  [selector]  →  {len(df)} rows  (filtered)")
    return df
 
 
def _from_input():
    print("\n  no _df_collect.csv")
    print("  [f] scan folder    [p] single path    [Enter] skip")
    choice = input("  → ").strip().lower()
 
    if choice == "f":
        folder = input("  folder path: ").strip()
        return _walk(folder)
    if choice == "p":
        path = input("  file path: ").strip()
        name = os.path.basename(path)
        _, ext = os.path.splitext(name)
        return pd.DataFrame([{
            "file_name":  name,
            "file_path":  path,
            "extension":  ext.lower(),
            "size_mb":    round(os.path.getsize(path) / 1e6, 3) if os.path.exists(path) else 0,
        }])
    return pd.DataFrame()
 
 
def _walk(folder):
    rows = []
    for root, _, files in os.walk(folder):
        for f in files:
            full = os.path.join(root, f)
            _, ext = os.path.splitext(f)
            rows.append({
                "file_name":  f,
                "file_path":  full,
                "extension":  ext.lower(),
                "size_mb":    round(os.path.getsize(full) / 1e6, 3),
            })
    df = pd.DataFrame(rows)
    print(f"  [selector]  →  {len(df)} rows  (scanned folder)")
    return df

## 0. The one-minute version
 
- `_u_entries.py` is the only file a human edits. You read it. You never put logic in it.
- Logic lives in function files: functions only, nothing runs on import.
- Every builder has one front door, `run.py`. `auto.py` finds every `run.py` and runs them in order.
- Never create an environment or install a package without asking first.
- Data moves one way: raw → processed → exports. Nothing writes back into raw.
- Done means `python auto.py --check` passes and you can name the function you changed and why.

## 3. `_u_entries.py`: what goes in, what never does
 
```python
# _u_entries.py  ·  edit this file, nothing else
TICKERS     = ["AAPL", "NVDA", "ASML"]
START, END  = "2018-01-01", "2026-06-30"
HORIZON     = 5            # trading days ahead
SEED        = 7
INPUT_DIR   = "data_in"    # relative to the app root
RUN         = {"builder_1": True, "builder_2": True, "builder_3": False}
```
 
- Allowed: literals, lists, dicts, dates as strings, booleans.
- Never allowed: imports, functions, loops, file reads, `if`, computed paths.
- A path is relative to the app root. An absolute path may live here and nowhere else.
- A new parameter gets a one-line comment saying what it changes.
 
## 4. Function files: how a function is written
 
- One job per function, named for what it returns: `get_prices_GET_df`, `clean_gaps_ffill_GET_df`.
- A stage function takes `(df, paths, cfg)` and returns `df`. Paths and cfg come in. They are never built inside.
- Each file imports what it uses at its own top. Files in `_0` to `_4` never import each other. Only `_5_fns_utils` is shared.
- Nothing runs at import time: no top-level calls, no prints, no reads.
- A function that writes a file says so in its name (`_save_`, `_export_`) and returns the path it wrote.
- Raise errors with the stage and the reason (`ValueError("clean: 3 tickers have no rows after 2024-01-02")`). Never pass on them silently.
 
## 5. `run.py`: one builder, one front door
 
```python
import sys
from pathlib import Path
 
HERE = Path(__file__).resolve().parent
ROOT = HERE.parents[1]                       # app/
sys.path[:0] = [str(ROOT), str(HERE)]
 
import _u_entries as U                        # RULE 1: everything starts here
from src._0_fns_get.fn_get_data import get_prices_GET_df
from src._1_fns_clean.fn_clean_data import clean_gaps_ffill_GET_df
 
PATHS = {k: HERE / "data" / k for k in ("raw", "processed", "exports")}
CFG = {"tickers": U.TICKERS, "start": U.START, "end": U.END, "seed": U.SEED}
 
 
def main(check=False):
    df = get_prices_GET_df(None, PATHS, CFG | {"check": check})
    df = clean_gaps_ffill_GET_df(df, PATHS, CFG)
    print(f"✓ builder_1 · {len(df)} rows")
    return 0
 
 
if __name__ == "__main__":
    raise SystemExit(main(check="--check" in sys.argv))
```
 
- `run.py` composes the stages and does nothing else. Logic lives in function files.
- `--check` runs the whole flow on a small, cached slice with no network, no training and no writes outside `data/`.
- The exit code is the truth: 0 means it worked, anything else means it failed.
 
## 6. `auto.py`: finds every `run.py`
 
```python
"""auto.py · runs builders/*/run.py in number order. `python auto.py [--check] [--only 2]`"""
import re, subprocess, sys
from pathlib import Path
 
HERE = Path(__file__).resolve().parent
ROOT = HERE.parent
sys.path.insert(0, str(ROOT))
import _u_entries as U
 
def builders():
    found = [p for p in HERE.glob("builder_*/run.py")]
    return sorted(found, key=lambda p: int(re.search(r"\d+", p.parent.name).group()))
 
def main(argv):
    only = argv[argv.index("--only") + 1] if "--only" in argv else None
    for run in builders():
        name = run.parent.name
        if only and name != f"builder_{only}":
            continue
        if not U.RUN.get(name, True):
            print(f"·  {name}  off in _u_entries.RUN"); continue
        print(f"▶  {name}")
        code = subprocess.call([sys.executable, "run.py", *(["--check"] if "--check" in argv else [])], cwd=run.parent)
        if code:
            print(f"✗  {name} exited {code}. Stopping here."); return code
    print("✓  all builders ran"); return 0
 
if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```
 
- Each builder runs in its own process from its own folder, so one builder can't break another.
- It stops at the first failure and names it. It never skips ahead.
- A new `builder_N/run.py` is picked up on its own. Nothing is registered by hand.
 
## 7. RULE 4 in practice: environments
 
1. Before any `pip`, `conda` or `uv` command, ask: "Do you want to create a new environment?"
2. If no, ask: "Which environment should be used?" Use that one exactly, and say its name back.
3. A missing package is reported, never installed: `pandas-ta missing in <env>. Add it?`
4. Once a package is approved it goes into `requirements.txt` in the same change.
5. Never touch the base env, global Python, or another project's env.
 
## 8. Finance law: what makes the numbers worth trusting
 
- **No look-ahead.** A feature at day t uses data up to t and nothing after. Targets are shifted forward, features are never shifted back.
- **Fit on train only.** Scalers, PCA and imputers are fitted on the training window and applied to the rest.
- **Time splits, never shuffles.** Walk-forward or expanding windows. Each fold reports its own metrics.
- **Name the target.** Say what is predicted (for example, the log return `HORIZON` days ahead) and keep it fixed across models.
- **A baseline first.** Last value, then a linear or ARIMA model. An LSTM has to beat both before anyone sees it.
- **Report the spread.** Give MAE, RMSE and directional accuracy per fold, plus the interval coverage when a model gives a distribution.
- **Fix the seed.** Seeds come from `_u_entries.SEED`, so a result can be run again and come out the same.
- **Raw is a snapshot.** Pulls land as `data/raw/<source>_<YYYYMMDD>.csv` and are never edited. Cleaning writes to processed.
- **Fill gaps forward.** Use the trading calendar, forward-fill only, and never back-fill across a split.
- **No live orders.** Nothing here places a trade or moves money. Results are research, not advice.
